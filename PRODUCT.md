# Product context

This is a design-tool index of confirmed repository requirements, not a new product authority. `docs/core/product_requirements.md` and `docs/core/application_design.md` govern. No new interview or product claims are inferred.

## Platform

adaptive

## Users

Journey participants capture selected moments; coauthors and designated publishers compose one shared account; visitors read approved journeys and dated practical observations.

## Product Purpose

A shared record of a journey that happened. Capture, compose, experience and learn retain one journey identity and explicit source permissions.

## Capabilities and Constraints

The current work is a fictional P00–P02 prototype, not a functioning capture, sync, publication or authentication service. Existing Expo/React Native/Unistyles mobile and React/TanStack web applications remain the implementation. No scope expansion to P03. Documentation owns permission and evidence semantics.

## Brand Commitments

The application design specifies a contemporary photographic field journal, Newsreader and Instrument Sans, Paper/Forest/Clay roles and evidence-aware journey lines. The user rejected the first text-heavy specimen implementation and requested a modern, inviting, visually richer system inspired by their supplied travel-app image, without copying its colors or feature model.

## Evidence on Hand

`tests/fixtures/prototype` holds fictional actors and journey content. Purpose-created images must be labelled sample imagery and carry provenance. Real journey photos, testimonials and production acceptance do not exist here.

## Accessibility & Inclusion

Readable long text, visible focus, semantic states, reduced motion, 44 CSS px web and 48 dp Android targets. Native platform evidence is separate from responsive web evidence.
